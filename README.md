# QwantStudy — квантовая физика в 3D

Интерактивный учебный сайт: 3D-атлас микромира в духе анатомических атласов, понятия, история, тест и голосовой гид.

## Возможности
- **3D-атлас** (three.js): 7 моделей (атом, подробное ядро с кварками и глюонами, опыт с двумя щелями, сфера Блоха, запутанность, туннелирование, квантовый компьютер) и 46 структур. Есть выбор кликом, подписи, рентген, каркас, разнесение частей, изоляция и скрытие структур, поиск, снимок экрана и полноэкранный режим.
- **Голосовой гид**: тур из 17 шагов с естественным голосом и субтитрами с подсветкой слов. Все фразы сайта (тур, понятия, история, структуры, тест) заранее озвучены нейросетью OmniVoice через проект VoiceStudio. Если файла нет, сайт переключается на голос браузера (Web Speech API).
- **Голосовое управление**: «дальше», «назад», «пауза», «атом», «кубит», «рентген», «разбери», «тест» и другие команды; ответы в тесте голосом.
- **Понятия**: 10 карточек с формулами. **История**: 17 вех с 1900 по 2025 год с фильтром по эпохам. **Тест**: 7 вопросов.
- Клавиатура: `Пробел`, `← →`, `1–7`, `X W L E R A F P M`, `Esc`.

## Запуск
Сборка не нужна, three.js лежит в `lib/three`, интернет для 3D не нужен. Нужен любой статический сервер (двойной клик по index.html не сработает: браузер блокирует модули на file://):

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Для GitHub Pages: Settings → Pages → Deploy from branch → корень ветки.
Распознавание речи лучше всего работает в Chrome и Edge.

## Озвучка (OmniVoice / VoiceStudio)
Аудио лежит в `audio/voice/` (`<хеш>.mp3` и `manifest.json`). Ключ — хеш произносимого текста, поэтому при изменении текста в `js/data.js` или `js/scenes.js` фразу нужно переозвучить. Пока её не переозвучили, сайт сам прочитает её голосом браузера.

```bash
git clone https://github.com/debpalash/VoiceStudio            # пакет omnivoice
pip install torch "transformers>=5.10" accelerate pydub soundfile psutil faster-whisper
node tools/list-texts.mjs > texts.json                         # все фразы сайта
PYTHONPATH=VoiceStudio python tools/generate-voice.py build --ref tools/voice-reference.wav --texts texts.json --steps 16
python tools/check-voice.py texts.json                         # проверка Whisper-ом
PYTHONPATH=VoiceStudio python tools/generate-voice.py build --ref tools/voice-reference.wav --texts texts.json --only <ключи> --seed 11
```

Голос создан через voice design (`female, young adult, moderate pitch`), эталон — `tools/voice-reference.wav`. Остальные фразы озвучены клонированием эталона, поэтому голос везде одинаковый. Формулы и символы перед озвучкой превращаются в слова (`js/speech.js`).

**Лицензия голоса.** Веса модели OmniVoice распространяются по лицензии CC BY-NC 4.0: аудио можно использовать только в некоммерческих целях и с указанием авторства (указано в подвале сайта). Для коммерческого проекта переозвучьте сайт другой моделью.
