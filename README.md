# QwantStudy — квантовая физика в 3D

Интерактивный учебный сайт: 3D-атлас микромира в духе анатомических атласов, понятия, история, тест и голосовой гид.

## Возможности
- **3D-атлас** (three.js): 7 моделей (атом, подробное ядро с кварками и глюонами, опыт с двумя щелями, сфера Блоха, запутанность, туннелирование, квантовый компьютер) и 46 структур. Есть выбор кликом, подписи, рентген, каркас, разнесение частей, изоляция и скрытие структур, поиск, снимок экрана и полноэкранный режим.
- **Голосовой гид**: тур из 17 шагов с озвучкой (Web Speech API), субтитрами с подсветкой слов, выбором голоса и скорости.
- **Голосовое управление**: «дальше», «назад», «пауза», «атом», «кубит», «рентген», «разбери», «тест» и другие команды; ответы в тесте голосом.
- **Понятия**: 10 карточек с формулами. **История**: 17 вех с 1900 по 2025 год с фильтром по эпохам. **Тест**: 7 вопросов.
- Клавиатура: `Пробел`, `← →`, `1–7`, `X W L E R A F P M`, `Esc`.

## Запуск
Сборка не нужна, three.js лежит в `lib/three`, интернет для 3D не нужен. Нужен любой статический сервер (двойной клик по index.html не сработает: браузер блокирует модули на file://):

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Для GitHub Pages: Settings → Pages → Deploy from branch → корень ветки.
Распознавание речи лучше всего работает в Chrome и Edge.
